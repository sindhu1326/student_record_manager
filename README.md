Student Record Manager

Overview

Student Record Manager is a Python-based command-line application designed to manage student information efficiently. The project demonstrates fundamental Python programming concepts, including regular expressions, file handling, input validation, and exception handling.

The application allows users to add student records, validate email addresses, store information in a file, and retrieve saved records.

Features

Add Student: Enter and store student details such as ID, name, age, and email.

Email Validation: Validates email addresses using Python's re module and Regular Expressions.

File Handling: Stores student records in a text file and retrieves them when required.

Input Validation: Ensures that user-provided data follows the expected format.

Exception Handling: Handles invalid inputs and prevents unexpected program termination.

Menu-Driven Interface: Provides a simple and user-friendly command-line experience.

Technologies Used

Python 3

Regular Expressions (re)

File Handling

Exception Handling

Command-Line Interface (CLI)

Installation and Usage

Prerequisites

Ensure that Python 3.x is installed on your system.

Clone the Repository

git clone https://github.com/your-username/Student-Record-Manager.git

Navigate to the Project

cd Student-Record-Manager

Run the Application

python student_record_manager.py

Application Workflow

The application provides options to:

1. Add a new student record.


2. Validate the student's email address.


3. Save the record to a file.


4. Read and display previously stored records.


5. Handle invalid inputs using exception handling.



Example stored record:

101, Sindhuri, 19, sindhuri@example.com
